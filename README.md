#🔒 SecurePass Pro

Générateur de mots de passe haute sécurité.

Une application web moderne au style "Cyberpunk" pour générer, analyser et copier des mots de passe robustes instantanément.

🔗 [CLIQUEZ ICI POUR LANCER L'APPLICATION](https://lerapeurdu62280-debug.github.io/SecurePass-Pro/)

⚡ Fonctionnalités

Génération instantanée : Créez des mots de passe de 6 à 32 caractères.

Analyseur de force en temps réel : Algorithme visuel qui évalue la robustesse (Faible -> Impénétrable).

Contrôle total : Activez/Désactivez Majuscules, Minuscules, Chiffres et Symboles.

Presse-papier : Copie en un clic avec animation de confirmation.

Sécurité Totale : Fonctionne 100% en local (JavaScript côté client), aucun mot de passe n'est envoyé sur internet.
